# The Canon

The universal, enforceable substrate true of *every* harness — conventions for agent-facing markdown and harness
structure, independent of language, project, or workflow, each rule carrying a stable, citable `canon:<slug>` id.

Read [`./routing.md`](./routing.md) when authoring, reviewing, or restructuring agent-facing markdown or a harness — or
to resolve a cited `canon:` id to the file that owns it.
